# Bake

Landing page tĩnh cho tiệm bánh / bakery — dự án freelance HTML/CSS.

## Cấu trúc dự án

```
Bake/
├── index.html          # Trang chính
├── css/
│   └── index.css       # Stylesheet chính
├── img/                # Hình ảnh (gallery, about, team, icons…)
├── js/                 # Scripts (sẵn sàng bổ sung)
└── README.md
```

## Công nghệ

- HTML5
- CSS3
- Google Fonts (Montserrat)

## Chạy dự án

Mở `index.html` trực tiếp trên trình duyệt, hoặc dùng một static server:

```bash
# Ví dụ với Python
python -m http.server 5500

# Hoặc dùng Live Server trên VS Code / Cursor
```

Sau đó truy cập `http://localhost:5500`.

## Trạng thái

Đang xây dựng — markup cơ bản và CSS global đã có; nội dung các section đang được triển khai.
